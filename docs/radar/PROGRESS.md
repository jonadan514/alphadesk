재시도(코드 문제 아님).

## 2026-09-08 — 실적 축이 상수였던 문제 (절대 -> 상대 기준)

## 2026-09-09 — (별도 저장소) ai-briefing-bot 일간 브리핑 실패 수정

사용자가 다른 저장소(`jonadan514/ai-briefing-bot`)의 실패한 잡을 물어봄.

**원인**: `is_valid_url()`이 말줄임표(…)가 붙은 잘린 URL을 검증하려다

**수정**: 단순히 예외를 삼키면 한글 경로 URL(`.../wiki/한국`) 같은 정상
링크까지 버려지므로, `_to_ascii_url()`로 퍼센트 인코딩을 먼저 시도하고
(ASCII 특수문자는 safe에 넣어 이중 인코딩 방지), 그래도 실패하면
UnicodeEncodeError를 잡아 그 링크만 무효 처리한다.

**검증**: 회귀 테스트 3개 추가 후, 수정 전 코드에 대해 실행하면 두 개가
