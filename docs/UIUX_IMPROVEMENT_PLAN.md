# AlphaDesk UI/UX 개선 전달 문서

> 대상: Claude Code  
> 목적: 현재 AlphaDesk의 기능과 투자 로직은 유지하면서, 화면의 정보 위계·가독성·행동 유도성을 개선한다.  
> 기준 자료: `README.md`, `docs/PAGES.md`, 홈·워치리스트·워치리스트 상세·매수 체크·리스크 화면 캡처

---

## 1. 프로젝트 이해

AlphaDesk는 단순 종목 추천 앱이 아니라 다음 투자 흐름을 하나로 연결한 **개인용 투자 의사결정 시스템**이다.

```text
시장 진입 가능 여부 판단
→ 유리한 섹터 확인
→ 후보 종목 발굴
→ AI 투자 논리·리스크 검토
→ 워치리스트 관리
→ 매수 조건 검증
→ 포지션 사이징
→ 거래 기록
→ 성과·VaR·집중도·낙폭 관리
```

현재 기술 구조는 다음과 같다.

- 프론트엔드: Next.js 15 App Router, React 19, TypeScript, Tailwind
- 분석 엔진: Python
- 데이터베이스: Turso(libSQL)
- 자동화: GitHub Actions
- 배포: Vercel
- 대상 시장: 미국 S&P 500, 한국 KOSPI
- 핵심 사용자: 제작자 본인 1인
- 핵심 UX 목표:  
  **“지금 진입해도 되는가 → 어떤 종목인가 → 얼마를 사야 하는가 → 산 뒤 위험하지 않은가”를 빠르게 판단**

---

## 2. 현재 UI의 핵심 정체성

현재 UI는 거의 검은 배경, 앰버 포인트, 각진 카드, 모노스페이스 중심의 **터미널 앰버 테마**를 사용한다.

이 방향은 AlphaDesk와 잘 맞으므로 폐기하지 않는다.

### 유지할 요소

- 검은 배경과 앰버 브랜드 컬러
- 왼쪽 고정 사이드바
- 미국·한국 시장 전환 탭
- 티커·숫자·점수의 모노스페이스 표현
- 각진 카드와 낮은 장식성
- `GO / CAUTION / STOP`
- `risk_on / neutral / risk_off / crisis`
- 초록·노랑·주황·빨강의 시맨틱 상태 색상
- 전문 도구·관제 시스템 같은 분위기

### 변경해야 할 방향

터미널 외형은 유지하되, 정보 구조는 현대적인 의사결정 대시보드 방식으로 재정리한다.

> 터미널 스타일은 브랜드 표현에 사용하고,  
> 본문 가독성·카드 위계·행동 유도는 별도로 개선한다.

---

## 3. 가장 중요한 UX 원칙

모든 화면은 다음 구조로 읽혀야 한다.

```text
현재 상태
→ 그 이유
→ 사용자가 지금 해야 할 행동
```

예시:

```text
조선업 ETF 비중 23.8%
설정 상한 25%에 근접
이번 달 신규 매수 제외
```

숫자와 상태만 보여주지 말고, 가능한 경우 **다음 행동**까지 한 화면에서 제시한다.

## 4. 전역 UI 개선 방향

### 4.1 폰트 역할 분리

현재는 화면 전체가 모노스페이스 성격이 강해 한글 본문 가독성이 떨어진다.

#### 권장

- 한글 제목·본문·설명: 가독성 높은 산세리프
- 티커·수치·점수·날짜·코드성 데이터: 모노스페이스
- 버튼·탭: 기존 톤 유지 가능
- 긴 AI 분석 문장: 산세리프 + 충분한 행간

#### 목표

- 화면 정체성은 유지
- 장시간 읽기 피로 감소
- 숫자와 설명의 역할 구분

---

### 4.2 텍스트 명도 개선

현재 보조 설명과 회색 텍스트가 너무 어둡다.

#### 개선 대상

- 카드 보조 문구
- 날짜
- 지표 설명
- 표의 섹터명
- 도움말
- 입력 안내 문구
- AI 분석 본문

#### 원칙

- 핵심 본문은 현재보다 밝게
- 낮은 명도는 정말 부차적인 정보에만 사용
- 모든 설명을 흐리게 처리하지 않기

---

### 4.3 카드 계층 3단계 도입

현재는 거의 모든 정보가 비슷한 카드와 테두리를 사용해 중요도가 평평해 보인다.

#### Primary Card

오늘의 최종 판단, 즉시 행동, 핵심 위험

- 강한 배경 구분
- 큰 상태 텍스트
- 넓은 여백
- 한 화면에 1~2개

#### Secondary Card

판단 근거, 세부 상태, 주요 기능

- 일반 카드
- 적당한 테두리
- 제목과 값이 명확

#### Tertiary Section

참고 표·세부 지표·설명

- 카드 테두리 최소화
- 섹션 배경 또는 구분선 위주
- 한 화면에 너무 많은 박스가 생기지 않도록 처리

---

### 4.4 상태 반복 최소화

동일한 결론을 여러 카드에서 반복하지 않는다.

예: 홈 화면에서

- 종합 판단 `GO`
- 마켓 게이트 `GO`
- 우측 종합 판단 `GO`
- 체제 `risk_on`

이 각각 별도 카드로 보이기보다 다음처럼 통합한다.

```text
오늘의 판단: GO
신규 진입 가능 · 권장 투자 비중 70~80%

근거
체제 Risk-on · 게이트 통과 · 신용위험 안정

주의
SPY 다음 주 약세 확률 57%
```

---

### 4.5 미입력과 실패 상태 구분

체크리스트에서 아직 사용자가 값을 넣지 않은 상태를 실패처럼 보여주지 않는다.

#### 상태 권장

- `PASS`: 자동 조건 통과
- `WARN`: 확인 필요
- `FAIL`: 실제 기준 미충족
- `PENDING`: 아직 미입력 또는 미선택
- `INFO`: 판정에는 미포함되는 참고 항목

특히 매수 체크에서 티커 미선택 상태는 `3/12 통과`보다 다음 문구가 적절하다.

```text
종목을 선택하면 12개 조건을 검증합니다.
```

---

## 5. 정보 구조 제안

현재 메뉴는 기능별로 나뉘어 있으나, 사용자 흐름이 더 잘 보이도록 그룹화한다.

```text
오늘
 ├ 개요
 └ 주간 브리핑

시장
 ├ 시장 체제
 └ 섹터 분석

종목
 ├ 종목 분석
 └ 워치리스트

투자 실행
 ├ 매수 체크
 └ 포트폴리오

관리
 ├ 리스크
 └ 가이드
```

페이지를 삭제하지 않고 사이드바 그룹과 시각적 구분만 개선한다.

# 6. 화면별 개선안

---

## 6.1 홈

### 현재 역할

“지금 신규 진입 가능한 시장인가?”를 5초 안에 보여주는 대시보드.

### 현재 장점

- 시장 전환이 명확
- 체제·센서·지수·상위 종목이 한 화면에 있음
- 주요 판단이 상단에 배치
- 시장 판단 후 종목을 보는 흐름이 자연스러움

### 현재 문제

- 동일 판정이 반복됨
- 정보가 많지만 행동 문장이 약함
- 스크리닝 수, 마켓 게이트, 종합 판단이 모두 큰 KPI
- 사용자가 “그래서 오늘 무엇을 해야 하는지” 다시 해석해야 함

### 권장 구조

```text
[오늘의 투자 판단]
GO — 신규 진입 가능

오늘 할 일
1. 후보 5종목 검토
2. 동일 섹터 집중 확인
3. 신규 진입은 50% 분할 매수

주의 신호
SPY 다음 주 약세 확률 57%

[핵심 근거]
체제 Risk-on
마켓 게이트 통과
VIX 안정
Credit 안정

[관심 종목]
상위 5 알파 픽

[내 포트폴리오]
핵심 위험·경고만 요약
```

### 축소 또는 통합 대상

- 종합 판단 카드와 마켓 게이트 카드 통합
- 우측 종합 판단 중복 제거
- 스크리닝 종목 수는 보조 정보로 이동
- 지수 현재가는 상세 섹션으로 이동 가능

### 완료 기준

홈 진입 후 5초 이내에 아래 3개를 알 수 있어야 한다.

1. 지금 진입 가능한가
2. 오늘 검토할 종목이 있는가
3. 포트폴리오에 위험 신호가 있는가

## 6.2 워치리스트

### 현재 역할

- 스크리닝 후보 탐색
- 내가 선택한 관심 종목 관리
- 재무·체제·기술·AI·정성 검토 연결

### 현재 장점

- 후보와 내 워치리스트 분리
- 성장·배당·중립 필터
- 적합점수·재무지표·체제 정보 동시 제공
- 표에서 바로 종목 추가 가능

### 현재 문제

- 상단 대형 KPI 4개가 화면을 많이 차지
- “오늘 관심도 상승”이 한 줄 티커 나열이라 읽기 어려움
- 표가 가로로 길고 지표가 많음
- 종목 탐색보다 통계 카드가 먼저 보임

### 권장 상단 구조

```text
스크리닝 후보 76    내 워치리스트 11

분류
전체 76 · 성장 23 · 배당 51 · 중립 2

오늘 주목할 변화
ABNB  Cold → Warm
ZBRA  Warm → Hot
TDY   Warm → Hot
+ 5개 더 보기
```

### 표 컬럼 우선순위

1. 티커·종목명
2. 적합점수
3. 체제 적합
4. 투자 유형
5. 재무 상태
6. 섹터·시가총액

### 재무지표 표현 개선

표에서 F-Score·부채비율·이자보상배율을 각각 별도 컬럼으로 유지할 수도 있지만, 탐색성을 높이려면 요약 배지를 고려한다.

```text
재무 우수
F-Score 7/9 · 부채 20.5% · 이자보상 55.6×
```

상세 화면에서는 모든 수치를 그대로 제공한다.

### 완료 기준

- 첫 화면에서 종목 리스트가 더 위로 올라와야 함
- 사용자가 후보를 찾고 추가하는 행동이 1차 목적이 되어야 함
- 상단 통계는 보조 역할이어야 함

## 6.3 워치리스트 상세

### 현재 역할

종목별 투자 리서치 노트.

### 현재 포함 정보

- 시장·투자 유형
- 적합점수
- 상대수익률
- F-Score
- 부채비율
- 이자보상배율
- 영업현금흐름
- 체제 적합도
- 가격 차트
- RSI·MACD·이동평균
- 네러티브 브리프
- 촉매·리스크
- 정성 체크리스트

### 가장 큰 문제

현재 우측 패널 폭이 너무 좁다.

#### 발생하는 문제

- 차트가 작음
- AI 문장이 좁은 폭에 길게 표시됨
- 카드가 과도하게 분절됨
- 스크롤 길이가 과도함
- 종목 맥락을 한눈에 파악하기 어려움

### 권장 형태

데스크톱에서 최소 700px, 권장 760~900px의 우측 패널 또는 전체 상세 페이지.

```text
┌─────────────────────────────────────────────┐
│ DXCM                         [닫기]          │
│ 성장 · Healthcare · $29.6B                  │
├───────────────────┬─────────────────────────┤
│ 핵심 판단          │ 기술적 상태              │
│ 적합점수 85        │ 차트                     │
│ 체제 적합 성장     │ RSI / MACD / 이평        │
├───────────────────┴─────────────────────────┤
│ 투자 논리                                   │
│ 촉매              리스크                    │
├─────────────────────────────────────────────┤
│ 정성 체크리스트                             │
├─────────────────────────────────────────────┤
│ [워치리스트 메모]   [매수 체크로 이동]       │
└─────────────────────────────────────────────┘
```

### 정보 순서 권장

1. 한 줄 결론
2. 핵심 투자 논리
3. 주요 리스크
4. 핵심 재무·체제 지표
5. 기술적 타이밍
6. 정성 체크
7. 매수 체크 이동

### 상단 결론 예시

```text
꾸준한 관심
재무와 체제는 양호하지만 단기 추세는 약함
```

### 공통 컴포넌트 정리

`top-picks`와 `watchlist` 상세에 비슷한 정보가 중복되므로 공통 구조를 검토한다.

#### 구분 원칙

- 종목 분석: 새로운 후보를 발견하는 탐색 화면
- 워치리스트: 선택한 종목을 지속 관리하는 화면

#### 가능한 공통 컴포넌트

- `StockSummaryHeader`
- `FundamentalMetrics`
- `TechnicalSummary`
- `NarrativeBrief`
- `CatalystRiskPanel`
- `QualitativeChecklist`
- `StockActionBar`

### 완료 기준

- 1개 종목의 전체 투자 맥락을 스크롤 초반에 이해할 수 있어야 함
- 차트와 AI 본문이 충분한 폭을 가져야 함
- 워치리스트 상세에서 매수 체크로 자연스럽게 이동할 수 있어야 함

## 6.4 매수 체크

### 현재 장점

- AlphaDesk 핵심 철학이 가장 잘 드러나는 화면
- 시장·체제·종목·AI·리스크·타이밍의 6단계 구조
- 오늘 할 일 안내가 좋음
- 실제 매수 전 통제 장치 역할이 명확
- 포지션 사이징까지 연결됨

### 현재 문제

- 상단 `5/6 정상`과 하단 `3/12 통과`가 서로 충돌해 보임
- 티커를 선택하지 않아도 미충족처럼 표시됨
- 후보 칩이 너무 많아 입력 전 화면을 차지
- 12개 항목이 자동·수동·입력 조건 구분 없이 한 번에 노출됨
- 포지션 사이징 결과보다 입력 폼이 더 강조됨

### 상단 상태 구분

```text
시장 환경       5/6 정상
선택 종목 조건  종목 선택 전
```

종목 선택 후:

```text
시장 환경       5/6 정상
선택 종목 조건  8/12 충족
```

### 후보 선택 UI

```text
종목 선택
[티커 또는 회사명 검색]

추천 후보
AMZN · CSCO · VRTX · INCY · FFIV
[전체 후보 보기]
```

### 12개 체크리스트 그룹화

#### 1. 자동 검증

- 시장 게이트
- 체제
- 워치리스트 후보 포함
- BUY 액션
- Grade A·B
- 종목 점수
- AI thesis 존재
- 리스크 허용 범위

#### 2. 사용자 판단

- 정성 검증
- 6개월 이상 보유 가능성

#### 3. 주문 계획

- 손절가
- 매수 수량

### 권장 상태 UI

```text
자동 검증       7/8 통과
사용자 판단     1/2 완료
주문 계획       0/2 입력
```

### 판정 로직 주의사항

이 페이지는 과거 다음 문제가 발생한 이력이 있으므로 UI 변경 시 반드시 검증한다.

- 원화·달러 컨텍스트 혼동
- 선행 섹터가 정보 항목인지 판정 조건인지 불일치
- 카드 문구와 실제 계산 로직 불일치
- 시장 전환 시 환율·통화 단위 오류

### 완료 기준

- 티커 선택 전에는 실패 상태가 없어야 함
- 자동 검증과 사용자 입력이 명확히 구분되어야 함
- 최종 매수 가능 여부가 한 문장으로 정리되어야 함
- 표시 문구와 실제 판정 로직이 일치해야 함

## 6.5 포지션 사이징

### 현재 문제

중요한 기능이지만 일반 입력 폼처럼 보여 결과의 존재감이 약하다.

### 권장 구조

```text
내가 감당할 최대 손실
총 투자 가능 자금      10,000,000원
거래당 허용 손실       1.0%
최대 손실 금액          100,000원

주문 조건
현재가                  $150
손절가                  $138.50
주당 위험               $11.50

추천 매수 수량          6주
예상 주문액             약 1,240,000원
포트폴리오 비중         4.1%
```

### 디자인 원칙

- `추천 매수 수량`을 가장 크게 표시
- 최대 손실 금액을 명확히 표시
- 예상 주문액·포트폴리오 비중을 함께 제공
- Kelly 검증은 `고급 검증`으로 접을 수 있음
- 미국·한국 시장에 따라 통화 단위가 명확히 표시되어야 함

### 완료 기준

사용자가 값을 입력한 뒤 가장 먼저 다음을 확인할 수 있어야 한다.

1. 몇 주 살 수 있는가
2. 총 주문액은 얼마인가
3. 최대 손실은 얼마인가
4. 포트폴리오에서 몇 %인가

## 6.6 리스크

### 현재 장점

- 단순 손익이 아니라 전문적인 위험 관리 제공
- 현재 투자 비중과 권장 비중 비교
- 현금 비중
- VaR
- 위험 예산 초과
- 섹터 집중도
- 종목 상관관계
- 종목별 위험 기여도
- 낙폭 분석

### 현재 문제

- 위험 정보가 너무 많은 위치에서 반복
- 사용자가 무엇을 줄여야 하는지 다시 해석해야 함
- 시스템 상태·경고·VaR·위험 기여도·낙폭이 동일한 무게로 보임
- 시뮬레이션 데이터가 실제 보유 자산처럼 보일 가능성

### 권장 상단 구조

```text
현재 리스크 상태: 주의

가장 먼저 할 일
1. 투자 비중 100% → 권장 80% 이하로 조정
2. VRT·JBL·FCX가 위험 기여도 상위
3. GOOGL·GOOG 중복 노출 확인

예상 효과
현금 20% 확보 시 VaR 약 2.3% → 1.8% 예상
```

### 리스크 정보 계층

#### 1단계: 즉시 조치

- 투자 비중 초과
- VaR 한도 초과
- 손절 임박
- 특정 종목 위험 기여도 과다

#### 2단계: 구조적 위험

- 섹터 집중
- 종목 간 높은 상관관계
- 동일 기업·유사 노출
- 장기 낙폭 위험

#### 3단계: 참고 분석

- 과거 CVaR
- 역대 최대 낙폭
- 상세 종목 표

### 시뮬레이션 표시

현재 화면은 시뮬레이션 포트폴리오를 실제 데이터처럼 오해할 수 있으므로 전역 상태를 명확히 표시한다.

권장 방식:

- 상단 고정 `SIMULATION` 배지
- 실제/시뮬레이션 탭
- 화면 배경에 아주 약한 워터마크
- 제목 옆에 현재 데이터 모드 표시

### 완료 기준

- 위험 상태를 본 뒤 사용자가 줄여야 할 종목·비중을 바로 알 수 있어야 함
- 경고를 나열하는 것이 아니라 조치 제안으로 변환해야 함
- 실제와 시뮬레이션이 혼동되지 않아야 함

# 11. 완료 후 기대 상태

AlphaDesk는 다음 인상을 주어야 한다.

> 시장 데이터를 많이 보여주는 앱이 아니라,  
> 사용자의 투자 원칙에 따라 오늘의 행동을 정리해주는 개인 투자 관제 시스템.

각 화면은 아래 질문에 명확히 답해야 한다.

| 화면 | 반드시 답해야 할 질문 |
|---|---|
| 홈 | 오늘 시장에 진입해도 되는가 |
| 시장 체제 | 왜 지금 이런 시장 판정이 나왔는가 |
| 섹터 분석 | 현재 어떤 섹터가 유리한가 |
| 종목 분석 | 새롭게 검토할 종목은 무엇인가 |
| 워치리스트 | 내가 계속 관찰할 후보는 무엇인가 |
| 종목 상세 | 이 종목의 투자 논리와 핵심 위험은 무엇인가 |
| 매수 체크 | 지금 실제로 매수해도 되는가 |
| 포지션 사이징 | 몇 주를 사야 감당 가능한가 |
| 포트폴리오 | 실제 성과가 벤치마크보다 나은가 |
| 리스크 | 무엇을 얼마나 줄여야 하는가 |

# 12. 핵심 요청 요약

1. 현재 터미널 앰버 정체성은 유지한다.
2. 기능보다 정보 위계와 가독성을 먼저 개선한다.
3. 모든 화면 상단에 상태·이유·행동을 정리한다.
4. 동일 판정 반복을 줄인다.
5. 종목 상세 패널을 크게 확장한다.
6. 매수 체크를 자동 검증·사용자 판단·주문 계획으로 나눈다.
7. 포지션 사이징 결과를 입력보다 크게 보여준다.
8. 리스크 화면은 경고 목록이 아니라 조치 제안 중심으로 바꾼다.
9. 미입력과 실패를 구분한다.
10. UI 문구와 실제 판정 로직의 일치를 최우선 검증한다.
